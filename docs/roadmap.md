# Roadmap

## Phase 1 - Research Foundation
- Define source standards (primary sources first)
- Collect inference estimates for text models
- Collect inference estimates for image and video models
- Collect context comparators (transport, streaming, search, etc.)

## Phase 2 - Modeling
- Normalize all values to Wh and mL per action
- Build uncertainty bands (low/mid/high)
- Build training amortization scenarios (conservative, central, aggressive)

## Phase 3 - Product UX
- Top-level toggle: include training / exclude training
- Interactive usage estimator for AI activities
- Context card equivalents for non-AI activities
- Assumption and citation panel

## Phase 4 - QA and Narrative
- Validate against external benchmarks
- Sensitivity tests for major assumptions
- Final content pass for plain-language clarity
